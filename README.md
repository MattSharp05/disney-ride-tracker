# Ride Log

Check off and rate every ride at Walt Disney World's four parks — Magic Kingdom, EPCOT, Hollywood Studios and Animal Kingdom.

- Punch a ride's ticket stub when you've ridden it
- Rate each ride 1–5 on thrill, line experience, theming, re-ride value and overall
- Track times ridden, last-ridden date and notes
- Sort by land, A–Z or your own top-rated list
- Add rides that aren't listed
- Data saves in your browser; use **Backup** to download/restore it on another device

Ride list is current as of October 2026. Edit `src/data/rides.ts` to update it.

## Develop

```bash
npm install
npm run dev
```

Built with Vite + React + TypeScript. Deployed on Vercel.
